# Prompting Rules

- Ground every rewrite in supplied bullet ids and safe reframes.
- Prefer conservative restatement over aspirational phrasing.
- Keep profile framing and experience selection distinct.
- Use job-specific ATS keywords only when the canonical source supports them.
- Treat unsupported domain claims as disallowed, not merely discouraged.
- Every output bullet should remain attributable to one or more source bullets.
